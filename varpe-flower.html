Overview

A flower decoration business takes most of its bookings by phone and WhatsApp. Enquiries, prices and event dates were easy to lose track of, and sending a proper quotation took time.

As a freelance project, I built the whole system on my own: a public website in Next.js for customers, and a Laravel admin app the team uses mostly on their phones, from the first enquiry to the accepted quotation and the reminder the day before the event.

Problems I solved

  1. 01

    A customer could accept an outdated quotation

    Problem. If the team changed a quotation while the customer had it open, the customer could still press Accept on the old prices.

    What I did. Every change, even to the items alone, makes a new version, and Accept checks that the customer saw the latest one. The quotation is locked while it is accepted, so two clicks cannot accept it twice, and an accepted quotation can no longer be edited.

  2. 02

    Sharing the PDF did not work on every phone

    Problem. Some phones would not share the PDF together with the message, some could not share files at all, and sharing could start before the PDF had finished loading.

    What I did. The Share button waits for the PDF and then tries the best option the phone supports: the file with the message, then the file alone, and otherwise WhatsApp opens with a link to the PDF.

  3. 03

    Opening a quotation could block the Accept button

    Problem. All the rate limits counted on one shared counter per visitor, so a customer who opened their quotation a few times could be blocked from accepting it.

    What I did. Each limit got its own named counter, so viewing a quotation and accepting it no longer count against each other.

  4. 04

    Reminders would not start on Windows

    Problem. The push notification keys for event reminders could not be created on a Windows computer, so the admin would not open there.

    What I did. The keys are now made with the project's own OpenSSL settings, so the admin works the same on Windows and on the server.
